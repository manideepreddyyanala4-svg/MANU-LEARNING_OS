# Acceptance gates before a future resume is approved

Knowledge-base status is **CONDITIONALLY READY**; final-resume readiness is **NOT ASSESSED — no resume produced**. These are review procedures informed by the source limitations in 16, the JDs and S16/S37, not an employer certification.

| Gate | Current result | Required pass evidence |
|---|---|---|
| A Source integrity | CONDITIONAL | Every material claim has an exact source and inspection scope; partial/blocked references remain visible. The export preserves original hashes and source checks. |
| B Personal claims | CONDITIONAL | Each chosen factual component has appropriate personal evidence or explicit self-report status. Unresolved achievements are omitted, narrowed or verified before inclusion. |
| C Projects | BLOCKED for quantitative/current-ownership claims | Approved protocol, dataset/version, completed log, unit/denominator, comparison and attribution; no superseded result or assumed production deployment. |
| D Publications | CONDITIONAL | 2023 publisher bibliography verified. Restricted work requires clearance. |
| E Recruiter evidence | CONDITIONAL | Taiwan-specific advice attributed to S14/S15/N12–N20; global guidance, marketing and editorial judgment not presented as binding Taiwan hiring rules. |
| F ATS design | PASS as specification only | Apply 19 to actual DOCX/PDF; retain extraction diff and page review. No actual future resume has passed yet. |
| G Interview defensibility | NOT ASSESSED | Candidate explains each selected technical claim and identifies personal/AI/team contributions; record assessment using 18. |
| H Role and eligibility | BLOCKED personally | Current JD/form, permit validity and counted hours, duration/enrollment, Thursday classes, commute, pay and language fit established. |
| I Privacy | PASS within inspected documentation scope | No secrets/private correspondence/raw lab data; private originals referenced safely. Recheck each actual public export and every new source addition. |
| J Maintainability | CONDITIONAL | README and ledgers identify current decisions, superseded history, unavailable originals, atomic claims and exact next evidence. Private sources require authorized owner access. |

## Line acceptance

For each selected line, open its row in [17](17_LINE_BY_LINE_CLAIM_VERIFICATION.csv). Check every factual component, verb/tense, role relevance and interview question. “Built,” “independently,” “deployed,” “optimized,” “led,” “published,” and “achieved” each imply evidence beyond tool presence. Replace no evidence with no claim; do not invent a smaller achievement. Conditional templates are not preapproved accomplishments.

Header, education, languages and aspirations may be usable as confirmed owner statements without a transcript for every word, provided the evidence level remains accurate. Formal grades, earned credentials, paid appointments, publication status and quantitative technical results need their appropriate originals. Optional missing awards or an irrelevant project need not block an otherwise truthful targeted resume.

## Role selection gate

| Role family | Conditional evidence emphasis | Main blockers |
|---|---|---|
| CV / image processing | Permitted dorsal ROI and protocol contributions | Corrected dataset lineage and personal work evidence. Check C++/ROS only if listed. |
| AI / ML | Defensible model evaluation, data handling and literature/reproduction boundaries | Exact completed results, split/selection logic; no automatic model-invention claim. |
| Python / software | Owned EvidenceOps endpoint/query/error-handling change | Coding fluency, algorithms, API/SQL task evidence and web skills where required. |
| LLM / RAG / agents | EvidenceOps retrieval, grounding and bounded tools | Owned changes, live-versus-mocked limits and bilingual evaluation; no production claim. |
| Data processing / analyst | Verified annotation/cleaning/provenance work for W100-like roles | Broader analyst SQL/statistics/visualization portfolio and original contributions absent. |
| Testing / AI QA | Scoped EvidenceOps regressions/API boundaries | Actual test authorship, issue reproduction and target device/ad-tech testing; Appier duration/onsite. |

These priorities are inferences, not confirmed opportunities, paid offers or eligibility. Recheck the specific role rather than every company in the historical directory. No resubmission, recruiter message, public push, deployment or resume generation is part of this review.
