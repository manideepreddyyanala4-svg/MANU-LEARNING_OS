# Section-by-section and line-level future resume blueprint

This is a set of candidate fragments and decisions, not an assembled resume. All user facts and personal ownership remain subject to evidence checks. No personal achievement line is unconditionally approved. Claim IDs resolve in [11](11_CLAIM_TO_SOURCE_LEDGER.csv); employer source IDs in [08](12_RESEARCH_SOURCE_REGISTER.csv). Sources supporting application relevance do not verify the candidate's ability.

Decision labels follow the stricter later instruction: APPROVED FOR FUTURE DRAFT, VERIFY FIRST, CONDITIONAL, EXCLUDE. Earlier INCLUDE/ROLE-SPECIFIC/OPTIONAL intent is expressed as CONDITIONAL; optional items may still require verification.

## Claim anatomy and better alternatives (C038; C122–C133)
| Weak/misleading fragment | Why it fails | Safer conditional candidate fragment |
|---|---|---|
| “Developed a state-of-the-art hand recognition model.” | Novelty, ownership and comparative result unverified. | “Contributed [owned task] to RGB dorsal-hand verification using [confirmed method].” |
| “Achieved [old EER] accuracy.” | EER is not accuracy; old protocols/cleaning may be superseded. | “Evaluated [model] under [approved protocol], reporting [verified metric and denominator].” |
| “Built a secure production RAG platform.” | Code presence is not sole authorship, production or security proof. | “Contributed [owned behavior] to an AI-assisted evidence-grounded RAG prototype.” |
| “Passed 84 tests.” | Log says nine skipped and does not identify personal work. | “Archived audit: 75 non-skipped offline test cases, nine skipped” only as project evidence until participation is confirmed. |
| “Hybrid BM25 + vector RAG.” | Current hybrid uses bilingual keyword rank plus dense rank; BM25 is separate. | “Keyword/vector rank fusion” if personally understood/used. |
| “Fluent bilingual engineer.” | User says beginner Mandarin. | “English — primary professional language; Mandarin — beginner” after confirmation. |

## Result gate before accepting a quantitative line
C028/C032/C038/C039: identify original record, artifact version, dataset manifest, split and session rule, model/config/preprocessing, threshold origin, numerator/denominator, baseline, date, final/preliminary status, ownership, and later corrections. For software checks identify revision, command, mocks/live boundaries, skips and date. If any part essential to the interpretation is absent, keep VERIFY FIRST. No current dorsal performance number is cleared.
