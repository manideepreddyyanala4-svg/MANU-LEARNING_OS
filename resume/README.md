# Manu OS resume knowledge base

This is the canonical evidence and job-research directory for future Taiwan technical internship applications. The two active projects are **RGB Dorsal-Hand Biometric Verification Research** and **EvidenceOps / Agent Reliability Lab**. Current decisions are dated November 23, 2026, Taipei time.

## Start here for an application

1. Check the exact posting and current hours, pay, enrollment, language and onsite requirements using the [Taiwan shortlist](24_TAIWAN_JOB_SHORTLIST_2026-11-23.md). Check previous applications in the private ManuOS tracker.
2. Open [current readiness](21_EVIDENCE_COLLECTION_STATUS_2026-11-19.md), the [claim ledger](11_CLAIM_TO_SOURCE_LEDGER.csv), and the [source register](12_RESEARCH_SOURCE_REGISTER.csv). Use the [line review](17_LINE_BY_LINE_CLAIM_VERIFICATION.csv) to check personal attribution, privacy and evidence limits.
3. Select the role from the [tailoring guide](08_ROLE_SPECIFIC_TAILORING.md). Use the [section blueprint](04_RESUME_SECTION_BLUEPRINT.md), [interview matrix](18_INTERVIEW_DEFENSIBILITY_MATRIX.md) and [ATS protocol](19_ATS_VALIDATION_PROTOCOL.md) before handing over a future DOCX or PDF.
4. Apply the [approval gates](22_CLAIM_APPROVAL_AND_INTERVIEW_GATES.md), [privacy policy](23_PRIVATE_APPLICATION_AND_SOURCE_POLICY.md) and [final acceptance gate](20_RESUME_FINAL_ACCEPTANCE_GATE.md). The [future drafting guide](15_FUTURE_RESUME_CREATION_GUIDE.md) gives the sequence.
