# Format, language and submission decisions
All decisions below are INFERENCE unless marked as a specific source's rule. Evidence: C001–C018, C037–C040; source register S01–S18, S21–S22, S29, S37.

Use [19 ATS validation protocol](19_ATS_VALIDATION_PROTOCOL.md) for the reproducible future DOCX/PDF checks. No actual new resume has been rendered, uploaded or certified. N12/N13 distinguish native 104 fields from the attached English file.

## Submission sequence for a later drafting task
C071 records the practical font/size/margin/date/filename suggestions as INFERENCE. They are not verified employer specifications.
1. Read current employer/form instructions, student-status and duration questions (C001/C019/C022).
2. Match only verified personal material to mandatory/preferred/duty requirements (C020/C021/C038).
3. Export the actual resume then select/copy text into a plain editor and check order, punctuation, dates, URLs and Chinese characters (C017).
4. Review autofilled fields; a successful upload is not proof of correct parsing (C011).
5. Record submitted version/date and exact availability statements privately when applications are separately authorized (C001).

## Versions and language
Maintain one factual evidence base. Future deliverables can include an English application master, reviewed Traditional Chinese variant if warranted, channel profiles, and role-targeted exports (C001/C015). Avoid a cramped bilingual duplicate on one page. Retain beginner Mandarin in every version; do not imply English-native status or a CEFR level without support (C144).

## What is actually verified about ATS
S16 says Greenhouse can fail to parse certain layouts and files over 2.5MB; it also says an unparsed resume can remain attached. This does not establish automatic rejection. The upload limit in a particular form may be larger: ITRI's current form lists 5MB and multiple formats, and uses a different provider. Treat upload, parsing and selection as different operations (C011–C012/C019).

## November 23 platform recheck

Keep a simple one-column source DOCX and a text-selectable PDF. Use one page as the default for the initial technical internship document. Use a second page only if a particular employer needs relevant evidence that cannot fit legibly. Follow the live form for its required format, fields, language and size. Check the PDF extraction order, dates, headings, characters and links. Treat platform previews and parsed fields as separate checks.

- Use 104's native structured fields and its English autobiography field where useful. A reviewed Traditional Chinese profile and an English technical attachment can coexist if the role and form allow it. [104 resume FAQ](https://www.104.com.tw/faq/resume)
- 1111 documents resume-page download and distinguishes native records from employer exports. Verify the actual form. [1111 resume FAQ](https://www.1111.com.tw/QA/faq_answer?aq=20&qno=635)
- Use Cake's native profile or requested attachment according to the listing. Its checker accepts PDF, DOC and DOCX, and that limit is scoped to the checker. [Cake resume checker](https://www.cake.me/ai-resume-checker/upload?locale=zh-TW)
- Yourator's PDF import guidance is scoped to the named import feature. Review all imported text and profile visibility. [Yourator import guidance](https://www.yourator.co/articles/533)
- LinkedIn Easy Apply and external Apply use different routes. Verify the exact destination and keep the application record there or in the private tracker. [LinkedIn official help](https://www.linkedin.com/help/linkedin/answer/a510363)
- Greenhouse identifies formatting patterns that hinder parsing. Its limits are vendor-specific. [Greenhouse support](https://support.greenhouse.io/hc/en-us/articles/200989175-Unsuccessful-resume-parse)

For AI-assisted work, describe actual design, integration, testing and decisions. Indicate AI assistance when it matters to the claim or the employer asks, then explain the code and decisions independently. Publications need an official citation and accurate status, while unpublished work requires disclosure clearance.
