## UNDERSTAND

A **pixel** is one location in an image grid. In a grayscale image, it stores one brightness number. In an RGB image, it stores three colour numbers.

**Width** counts columns across. **Height** counts rows down. **Resolution** here means width × height in pixels; it does not tell us an object's size in centimetres.

For a hand-image ROI (a selected region of interest), a point's position tells us which pixel to read. We will practise on a tiny synthetic grid, without using research images.

## MECHANISM

Image grid → choose (x, y) → find row y → find column x → read img[y, x].

Counting starts at **0**. The top-left pixel is (0, 0). Move right to increase x; move down to increase y.

A 6-column, 4-row grayscale image has shape **(4, 6)**. Shape lists height before width. Its last pixel is (x=5, y=3), not (6, 4).

## WORKED EXAMPLE

Read this example first, then explore the grid. The grid starts with the same values: 0 through 23, arranged in four rows.

```python
import numpy as np

img = np.arange(24).reshape(4, 6)
x, y = 4, 1
print("shape:", img.shape)
print("before:", img[y, x])
img[y, x] = 200
print("after:", img[y, x])
print("row 1:", img[1].tolist())
crop = img[0:3, 2:6]
print("crop shape:", crop.shape)
print("pixels:", img.size)
```

Output:

```text
shape: (4, 6)
before: 10
after: 200
row 1: [6, 7, 8, 9, 200, 11]
crop shape: (3, 4)
pixels: 24
```

`arange(24)` makes 0 through 23. `reshape(4, 6)` places them in four rows of six. Row 1 is the **second** row. At column 4 it contains 10; assignment replaces just that value with 200.

The crop keeps rows 0, 1, 2 and columns 2, 3, 4, 5. A slice excludes its stop value, giving three rows and four columns.

For colour, shape may be (4, 6, 3): 24 pixel locations and 72 channel values. A channel is one colour component at each pixel.

## COMMON MISTAKES

- **Swapping x and y:** img[4, 1] fails on this grid because row 4 does not exist. On a square image, swapped indices can silently read a different pixel.
- **Swapping dimensions:** a 640-wide, 480-high grayscale image has shape (480, 640). OpenCV size arguments such as cv2.resize use (width, height).
- **Counting the stop:** img[0:3, 2:6] excludes row 3 and column 6.
