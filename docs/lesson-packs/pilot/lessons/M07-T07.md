## UNDERSTAND

A **kernel** is a small grid of weights. A weight tells us how much a neighbouring pixel contributes to the output. A **linear filter** multiplies nearby image values by these weights and adds the products.

A 3 × 3 mean filter gives each of nine values weight 1/9. It produces their average. Other kernels can sharpen or detect changes; their outputs are not necessarily averages.

Filtering a hand ROI can change fine patterns and edge pixels. This toy demonstration explains the calculation; it does not recommend changing your research preprocessing.

## MECHANISM

Choose an output location → gather its 3 × 3 neighbourhood → multiply by weights → add nine products → write one output value.

Our convention is **cross-correlation**: keep the kernel in its displayed orientation, like OpenCV filter2D. Mathematical **convolution** flips the kernel horizontally and vertically first. For a symmetric mean kernel, both give the same answer.

At the corner, part of the neighbourhood lies outside the image. A **border mode** supplies those missing values. Zero uses 0. Replicate repeats the nearest edge pixel. Reflect-101 mirrors without repeating the edge pixel: for a row [1, 2, 3], its left extra value is 2.

Use the numbered steps below. Move to a corner and compare border modes. Switch to the asymmetric kernel to see why flipping can matter.

## WORKED EXAMPLE

Use numbers 1 through 25 in a 5 × 5 grid. At row 2, column 2, the neighbourhood is [7, 8, 9; 12, 13, 14; 17, 18, 19]. Their sum is 117. Dividing by 9 gives **13**.

At the top-left corner with zero padding, the neighbourhood is [0, 0, 0; 0, 1, 2; 0, 6, 7]. Its sum is 16; output is **16/9 ≈ 1.778**.

With reflect-101, it becomes [7, 6, 7; 2, 1, 2; 7, 6, 7]. Sum 45 gives **5**. Same image, same kernel, different border rule.

```python
import numpy as np
import cv2

img = np.arange(1, 26, dtype=np.float32).reshape(5, 5)
k = np.ones((3, 3), dtype=np.float32) / 9
for label, mode in [("zero", cv2.BORDER_CONSTANT),
                    ("reflect101", cv2.BORDER_REFLECT_101),
                    ("replicate", cv2.BORDER_REPLICATE)]:
    out = cv2.filter2D(img, -1, k, borderType=mode)
    print(label, "centre", round(float(out[2, 2]), 3),
          "corner", round(float(out[0, 0]), 3))
```

Output:

```text
zero centre 13.0 corner 1.778
reflect101 centre 13.0 corner 5.0
replicate centre 13.0 corner 3.0
```

`float32` keeps decimal results. `ones / 9` makes nine equal weights. `filter2D` computes every output location; `-1` keeps the input data type, which is floating point here. Each print reads the centre and corner of the result.

## COMMON MISTAKES

- **Calling every filter an average:** a mean kernel sums to 1; an edge kernel can contain negative weights.
- **Ignoring borders:** invented neighbours affect the outer pixels, even when the image shape stays the same.
- **Expecting filter2D to flip:** it performs cross-correlation. Flip an asymmetric kernel explicitly for convolution with the corresponding anchor.
- **Using uint8 output for signed results:** negative outputs can be clipped. Use an appropriate floating-point output for inspection.
