Do not assume a three-day full-time schedule is legal because an application form accepts it. The Thursday 09:00–15:00 class further restricts attendance; a Taipei or Zhudong commute from Taichung needs a realistic door-to-door calculation and pay-after-travel check. Mandarin requirements absent from an ad are **unknown**, not English-only acceptance.

Optional PostgreSQL/pgvector is a separate adapter, **not proof that the live app uses it**. A UCI Steel Plates Faults mode computes category counts from 1,941 records into summarized evidence; it is not an image classifier or raw-vector index. Documented Mode A and B videos show selected real local interactions, but are not a production deployment.

**Test evidence:** the November 11 local audit recorded **84 unit checks, 76 passed and 8 skipped**, and a green GitHub workflow was observed; these were **not rerun November 16**. A successful offline suite does not establish model answer quality. The README's tiny phrase-based real-model checks have no human-reviewed representative benchmark. Chinese answerable questions sometimes falsely refuse. Citation matching is mainly exact quotations and source IDs; it is **not full semantic claim validation**. Prompt-injection and approval boundaries have tests for selected patterns, not a systematic adversarial security certification. Local Ollama models, the user's lab machine, current environment secrets and new end-to-end runs could not be inspected. The resume's old “73 tests” statement is stale relative to the audit and should be corrected only after fresh verification; do not edit the resume in this task.

**Honest interview claim:** “I built an AI-assisted local RAG/agent portfolio app with FastAPI, SQLite/Ollama, several retrieval modes, bounded tools and citation checks; I can show repository, tests, demo and known failures.” Separate what you yourself can code and explain from what was AI-generated or copied; verify every claimed metric afresh before using it.
